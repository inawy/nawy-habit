# Nawy Habit icon assets

The SVG files in this directory are Google Material Symbols — Outlined, sourced from the official
[google/material-design-icons repository](https://github.com/google/material-design-icons).

- Upstream path: \`symbols/web/<name>/materialsymbolsoutlined/<name>_24px.svg\`
- License: Apache License 2.0; see [LICENSE](./LICENSE).
- Icons are vendored locally and rendered as CSS masks so their color follows \`currentColor\`.
- The upstream SVG path data is kept unchanged.

Selected symbols include interface controls plus the habit picker set: auto_awesome, menu_book,
water_drop, directions_walk, fitness_center, self_improvement, bedtime, restaurant, favorite,
school, savings, and volunteer_activism.
