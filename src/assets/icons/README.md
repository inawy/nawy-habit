# Nawy Habit icon assets

The SVG files in this directory are Google Material Symbols — Outlined, sourced from the official
[google/material-design-icons repository](https://github.com/google/material-design-icons).

- Upstream path: `symbols/web/<name>/materialsymbolsoutlined/<name>_24px.svg`
- License: Apache License 2.0; see [LICENSE](./LICENSE).
- Icons are vendored locally and rendered as CSS masks so their color follows `currentColor`.
- The upstream SVG path data is kept unchanged.
- Habit-picker symbols are a reviewed allowlist of neutral activities and objects. Pork/pig,
  alcohol, gambling, sexual/nude, occult, and other inappropriate imagery is not allowed.
- New artwork must be visually reviewed before it is added to the picker; symbol names alone are
  not enough. See [the icon policy](../../../docs/icon-policy.md).

Current habit-picker symbols: auto_awesome, menu_book, water_drop, directions_walk,
fitness_center, self_improvement, bedtime, restaurant (cutlery only), favorite, school,
account_balance_wallet (wallet), and volunteer_activism (hands holding a heart).

Additional interface actions: archive, edit, ios_share, and drag_indicator (six-dot grip used for
reordering; the path was written from the upstream shape without network access, so re-sync it
from the upstream file when convenient).
